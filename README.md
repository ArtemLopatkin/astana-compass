# Astana Compass

Городской ИИ-помощник для Астаны: проверяемые рекомендации, прогулки под доступное время, пешие маршруты, погода и ответы на русском, казахском и английском.

**Статус:** репозиторий координации и контрактов. Приложение ещё не реализовано. Документы описывают целевое поведение, а не уже готовые функции.

## Быстрый старт для независимого агента

1. Получите доступ к приватному репозиторию от владельца `chinusoid` через собственный GitHub-аккаунт. Не передавайте токены или пароли другим участникам.
2. Клонируйте `https://github.com/chinusoid/astana-compass.git`.
3. Прочитайте `AGENTS.md`, `PRODUCT.md`, `ARCHITECTURE.md`, `CONTRACTS.md` и свой `TASK-*.md`.
4. Создайте свою ветку от актуального `main`: `agent/NN-topic`.
5. Реализуйте задачу в своей области, приложите тесты и создайте PR. Merge делает координатор.

## Общая архитектура

Next.js / TypeScript frontend → FastAPI backend → независимые Python-модули данных, поиска, контекста и генерации → PostgreSQL / pgvector.

Начальные контракты находятся в `contracts.schema.json`; примеры — в `contracts.examples.json`. Это единственный источник схем на первом этапе. Перенос в `packages/contracts` выполняет только координатор отдельным согласованным PR.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-contracts.txt
.venv/bin/python verify_contracts.py
```

Проверка выше проверяет seed-контракты и примеры. Она не является тестом готового продукта.

## Что считаем завершением продукта

- Воспроизводимый автоматический сбор реальных POI с источниками и отчётом покрытия.
- Поиск и рекомендации учитывают локацию, ограничения, длительность и неизвестные сведения.
- Каждое фактическое утверждение имеет доказательство; идеи ИИ помечены отдельно.
- Пешие маршруты, открытость и доступность не выдаются за подтверждённые без данных.
- Полный интерфейс RU / KK / EN, доступность с клавиатуры, мобильный экран, состояния ошибок.
- Рабочий сквозной сценарий, измеренная оценка качества, развёртывание и комплект для защиты.

Данные из внешних источников сохраняют собственные лицензии и атрибуцию. Лицензия на код пока не выбрана владельцем. Секреты, точные пользовательские координаты, приватные исходные документы и большие дампы не коммитятся.
